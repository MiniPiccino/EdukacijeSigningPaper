# Admin Guide

This guide walks through the steps an admin should follow to update the Education Sign-In app when a new session is organized.

## 1. Open the Web App
- On the office desktop connected by LAN cable, open a browser and navigate to `http://10.16.18.109:8505`.
- On a tablet or phone connected to Wi-Fi, use `http://192.168.102.246:8505`.

Keep the browser open during the remaining steps.

## 2. Log in to the Admin Panel
1. Click **Admin** in the left sidebar.
2. Enter `step` for both **Username** and **Password**.
3. Press **Log in**.

## 3. Create the New Education Session
1. Scroll to the bottom of the admin page.
2. Fill in the session details under **Create session**.
3. Click **Create session** and wait for the success message.

## 4. Set the Session as Default
1. Scroll back to the top of the admin page.
2. In the **Education session** selector, choose the session you just created.
3. Click **Set as default session** (or the equivalent button) so new sign-ins use this session automatically.

## 5. Prepare the Attendee List
1. Open the shared Google Drive: `STEP Google Drive > DIGITALIZACIJA > Edukacija`.
2. Copy the attendee information from the template into the session spreadsheet.
3. Download or export the attendee list as a CSV/Excel file (columns: attendee_id, name, company, email, phone).

## 6. Upload Documents to the Web App
1. In the admin page, find **Replace attendee list**.
2. Upload the file prepared in the previous step.
3. Wait for the confirmation message indicating the list was uploaded successfully.
4. When the session is ready, download the **signature sheet (DOCX)** from the Downloads section—the document includes captured signatures for all projects, including EEN.

The session is now ready for participants to sign in. Repeat this process each time a new education session is scheduled.
